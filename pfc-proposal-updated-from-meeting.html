This document outlines the MVP (Minimum Viable Product) workflow for PFC's job request tracking system, built entirely within the Follow-Up Pathway platform. 1. User-Friendly Multi-Channel Intake

Different team members have different communication styles. The system meets everyone where they are—no forcing people to change their habits.

Intake Methods by User Preference:

  • Steve: Forwards emails to tickets@pfcgoc.com → Auto-creates ticket
  • DK: Texts request to PFC number → Auto-creates ticket
  • Sage AI: Call 1-800-PFC-SAGE, describe request → Auto-creates ticket
  • Anyone: Visit request.pfcgoc.com → Fill simple form → Auto-creates ticket
  • Front Desk: Internal dashboard → Create ticket while on call with client

✅ Design Principle: Path of Least Resistance

All roads lead to the same database. No matter how the request comes in, it automatically creates a ticket in Follow-Up Pathway with all the right people notified. No 20 fill-in-the-blank boxes. Just the essentials.

2. AI-Powered Smart Routing

Once a ticket is created, AI analyzes the request and determines which departments need to be involved. Not every request needs all departments—the system is smart about routing.

Five Departments in PFC Workflow:

  • Staffing: Identify and assign personnel (always needed for operational requests)
  • Logistics: Transportation, equipment, setup (job-dependent)
  • Finance: Job codes, billing, hourly rates (always needed)
  • Scheduling: Calendar coordination, shift assignments (always needed)
  • ESOC: Security assessments, geofencing, vulnerability analysis (when required)

💡 Example: Weekend Detail in Miami

AI Analysis: "Client needs 3 security personnel for Saturday event in Miami Beach, 6pm-2am"
Auto-Routing: ✅ Staffing (3 personnel) | ✅ Logistics (Miami location) | ✅ Finance (quote needed) | ✅ Scheduling (weekend shift) | ❌ ESOC (not required)

3. Time-Based Escalation System

No more tasks falling through the cracks. If someone doesn't respond, the system automatically escalates up the chain.

Four-Level Escalation Path:

  • Level 1 (2 hours): Reminder to assigned person (email + SMS)
  • Level 2 (4 hours): Team lead notification (email + SMS + call)
  • Level 3 (8 hours): Department manager alert (email + SMS + call)
  • Level 4 (24 hours): Executive team notification (Chris, Marco, Steve)

⚖️ Balanced Notifications

The system is selective about notifications—avoiding alert fatigue. Only critical escalations trigger multiple channels. Day-to-day updates use in-app notifications and @mentions.

6. Sage Voice AI Integration

Managers can simply call Sage AI and describe the request verbally. Sage captures the details and creates the ticket automatically—no typing, no forms.

Sage AI Capabilities (100% Confirmed):

  • Natural Language Input: "PFC Safeguards received client request for weekend detail in Miami..."
  • Key Detail Extraction: Client name, job type, date, location, personnel count
  • Auto-Ticket Creation: Creates opportunity in Follow-Up Pathway
  • Call Recording: Audio attached to ticket for reference
  • Immediate Confirmation: "Got it. Ticket #1237 created. HR, Finance, and Operations have been notified."

7. MVP Implementation: Crawl, Walk, Run

We don't build everything at once. Start with one use case, prove it works, get buy-in, then expand.

Phase 1 - Crawl (Weeks 1-2): Build MVP

  • Pick ONE use case: Weekend detail request (most common)
  • Set up Follow-Up Pathway pipeline and custom fields
  • Build Replit middleware for AI routing
  • Configure 2-3 intake methods (email, text, Sage AI)
  • Connect to 3 departments: Staffing, Finance, Scheduling
  • Basic escalation workflows (2hr, 4hr reminders)

Phase 2 - Walk (Weeks 3-4): Test & Iterate

  • Process 10-15 real tickets through the system
  • Gather feedback from DK, Steve, and other managers
  • Adjust intake methods based on what people actually use
  • Fine-tune AI routing based on accuracy
  • Build simple dashboard for Chris/Marco/Steve
  • Show ROI: "Here's how much time we saved"

Phase 3 - Run (Month 2+): Expand

  • Add more use cases: ESOC requests, driver details, etc.
  • Include Logistics and ESOC departments
  • Build out full escalation system (24hr executive alerts)
  • Create advanced dashboard with analytics
  • Add client portal (if needed)
  • Integrate with other systems (accounting, calendar, etc.)

✅ Success Criteria for MVP

Week 4 Goals:
• 80% of weekend detail requests go through system (not group texts)
• HR/Finance get notified immediately (not 2 days before)
• Average response time: under 2 hours
• User feedback: "This is easier than the old way"
• Executive visibility: Chris/Marco can see status without asking
